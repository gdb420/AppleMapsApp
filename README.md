# AppleMapsApp

A minimal iOS app that displays Apple Maps with full pan / zoom / rotate / pitch
gestures, plus extras: map-type switching, the user's current location, and
long-press pin drops.

## Stack

- Swift 5, UIKit, `MapKit` (`MKMapView`)
- iOS 16+ deployment target
- Project file generated with [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml` — edit the YAML, run `xcodegen generate`, and the `.xcodeproj` is regenerated cleanly.

## Running

```bash
brew install xcodegen        # one-time
xcodegen generate
open AppleMapsApp.xcodeproj
```

Then in Xcode: pick an iOS Simulator destination and press ⌘R.

## Project layout

```
AppleMapsApp/

├── AppleMapsApp.xcodeproj/              # generated, git-ignored
└── AppleMapsApp/
    ├── AppDelegate.swift
    ├── SceneDelegate.swift
    ├── MapViewController.swift          # all map logic + gesture handling
    ├── Info.plist                       # generated by XcodeGen from project.yml
    └── Assets.xcassets/                 # AppIcon, AccentColor
```

## How the map moves

`MKMapView` already supports pan, pinch-zoom, two-finger rotation, and two-finger
pitch out of the box (`isScrollEnabled`, `isZoomEnabled`, `isRotateEnabled`,
`isPitchEnabled` are all set to `true`). A long-press recognizer drops a
red `MKMarkerAnnotationView` pin at the touched coordinate, and the bottom-right
button recenters the map on the user's location.
